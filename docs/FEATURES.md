## このアプリだけの機能

- 起動時に前回の内容を即座に表示 (その後サーバーの最新に置き換え)
- 背面から戻ったときに自動で再接続し、取りこぼしを取り直す
- アプリを閉じていても通知 (プッシュ通知。配信アプリ不要) / 常時接続モード
- チャンネルごとの下書き保持 (アプリを閉じても残る)、送信失敗時の入力内容の復元
- 通知から直接「返信」「既読にする」。通知は送信者のアイコン付きの「会話」の形でチャンネルごとにまとめる
- 管理者によるパスワードのリセット (サーバーの API はあるが Web 版には無い)
- 他のアプリの「共有」から画像・ファイル・文章を送る
- 端末のフォントで描けない絵文字の除外
- 外付けキーボードで Enter 送信 (Shift+Enter で改行)

## Web 版にあってこのアプリに無いもの

- ↑キーで直前の自分のメッセージを編集 — スマホ向けでないため未対応 (長押しメニューから編集)
- PWA 固有の機能 (インストール・Service Worker)
